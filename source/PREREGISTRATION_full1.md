## 3. 噪声和阈值

同一种方式重跑的波动，用每道题 B_1-B_4 这四次独立运行来估计。

- **连续题**：阈值 T = max(B 四次的极差, 3 个百分点)。两组之差 Δ 满足 Δ > T 时判为"优于"；|Δ| ≤ T 时判为"差异未超过阈值"。
- **二值题**：每组只有一次结果，所以拿它和 B 的四次结果比。
  - 只有当 B 四次全部失败而该组成功，或者 B 四次全部成功而该组失败时，才判为"优于"或"劣于"，并且注明"单次观察"。
  - 其余情况一律判为"无法区分"。
- **到顶**：连续题里四组和 B 的四次都 ≥ 99 分，或者二值题里 B 四次全部成功、A 和 C 也都成功时，这道题标为"到顶"，只比成本。

## 4. 三个问题各怎么判（逐题判，不跨题平均）

- **Q1 直接调用够不够（A 对 B）**
  - A 不差于 B（连续题：A 优于 B 或差异未超过阈值；二值题：A 成功，且 B 四次全成功或全失败），并且 A 的积分少于 B：判为"直接调用即可"。
  - B 优于 A：判为"需要 harness"。
  - 其余：判为"无法判断"。
- **Q2 多跑几次再挑有没有用（Bx4 对 B）**
  - 连续题：Bx4 优于 B 判为"选择有用"，B 优于 Bx4 判为"选择反而更差"，其余判为"未检出"。
  - 二值题：只描述 Bx4 有没有选中成功的那一次。
- **Q3 自动改提示词有没有用（主比较：C 对 Bx4，两者算力相近）**
  - C 优于 Bx4：判为"改提示词本身有效"。
  - Bx4 优于 C：判为"C 不如多跑几次"。
  - 连续题里 C 优于 B 但不优于 Bx4：判为"提升可以用多跑几次解释"。
  - 其余：判为"未检出差异"。
- **成本**：报告各组积分相对 B 的倍数。两组判为"差异未超过阈值"或"无法区分"时，选型建议取较便宜的那组。
- **跨题汇总**：只统计各种判定出现在几道题上，不计算平均分。

以上规则由 `judge_full.py` 机械计算，结果写入 `runs/full1/judgement.md`。我对结果的解读写在这个文件之外，不能修改它给出的判定。
